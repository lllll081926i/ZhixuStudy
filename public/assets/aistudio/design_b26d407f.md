# 知序 Study — Material 3 设计规范与功能页面清单

版本：产品交互原型 V0.2 · 2026-11-04

## 1. 设计定位

- **目标设备**：Android 手机优先，平板/折叠屏适配。
- **开发技术**：Kotlin + Jetpack Compose + Material 3。预览页面为独立 HTML，不是 Android 应用。
- **体验关键词**：轻量、专注、舒适、可信、柔和矢量插画、可解释的智能导入。
- **插画策略**：仅用于首页欢迎区、复习引导、空状态、完成态；题干/选项/字段映射/重复审查不使用大面积插画。
- **视觉风格**：Material You 低对比色彩搭配 M3 控件和圆角；不使用拟物、玻璃遮罩和夸张的动画。

## 3. 导航架构

- **四个一级入口（底部栏）**：学习、题库、复习、统计。
- **其他页面**：由首页卡片、题库详情、设置或当前流程进入；上栏返回；不重复占用底部导航空间。
- **宽屏自适应**：紧凑屏幕用 NavigationBar，较宽屏幕使用 NavigationRail；题库列表与题目详情可采用 ListDetailPaneScaffold 双栏。
- **页面顶部**：TopAppBar / MediumTopAppBar，返回箭头仅用于二级页面；重要操作必须明确标注。
- **弹层**：ModalBottomSheet 处理字段小修正、去重策略、答题卡、文件信息；长表单使用独立 Screen。
- **浮动操作按钮**：题库页右下角为导入/新建入口，避免全局多个 FAB 冲突。

## 5. 智能导入规则

### 5.1 正式版推荐解析管线

`Uri -> 类型嗅探 -> 格式解析 -> 单元格/段落结构提取 -> 布局检测 -> 字段匹配 -> 规则预处理 -> 标准题目模型 -> 语义校验 -> 题目指纹 -> 库内/全库去重 -> 预览修正 -> 单次事务提交 -> 导入报告`

不得把低置信度推断偷偷写为正确答案。导入必须有 `sourceFile / sheet / row / rawValue / normalizedValue / confidence / ruleVersion / importBatchId` 的追溯字段。正确答案缺失或指向不存在选项时，默认不能进入正式题库。

### 5.2 表格识别

- 候选标题行：在前若干行中计算列名命中率、非空比例和字段分布，允许手动指定起始行。
- 工作表：枚举 Sheet，抽样展示每个 Sheet 的行列数；存在“题目”和“答案”双 Sheet 时支持关联键/题号匹配。
- 字段映射：题目、题型、选项、答案、解析、难度、章节、标签、来源、图片等。允许“一列内多选项”和“多个选项列”。
- 标准化：支持字母答案 `A`、`ACD`、`A,C,D`，数字答案需要结合选项列表和编号规则；判断题别名、全半角、换行、题号前缀。
- 自定义规则：预设名、正则表达式、顺序、启用范围、示例测试结果、冲突优先级、保存/导出/导入规则配置。
- 二次审查：校验冲突、无法确认题型、无效答案、空选项、同题不同答案、极高相似度文本。
- 安全：解析器不执行宏与附件；超大文件限额，ZIP/XML 扩展炸弹检测；取消导入且支持回滚。

### 5.3 重复题与“重复题库”

- **行级完全重复**：标准化题干、选项文本、答案相同；默认跳过。
- **答案冲突**：题干相同但答案或选项不同；默认跳过并提示人工对比。
- **跨题库重复**：允许保留并警告，不因为跨题库相同而自动删除。
- **文件级重复**：记录源文件 SHA-256、大小、文件名、导入批次和时间；仅用于提醒，不能仅凭文件名判定一致。
- **版本级差异**：同题修订的来源、解析、选项变更需保留日志。
- **学习记录保全**：覆盖题目、合并重复题或删除题时，需要确保已有错题、收藏、作答记录的引用可追溯或迁移；生产版要支持撤销导入批次。

### 5.4 原型真实性边界

- 此 HTML 原型读取简单的本地 CSV/TSV/JSON/TXT，并通过规则构造候选题目。
- XLSX/XLS/DOCX/PDF 在此原型中**不提取文件内容**；它们只用于演示未来原生解析器的 UI 流程。
- 置信度百分比、学习统计趋势属于演示值，不是 AI 计算结果或真实分析结论。
- 原型中的确认导入修改的是运行时内存；刷新即恢复。

## 7. 验收用例

1. 首次打开：首页、题库、复习、统计四个主入口切换正常；返回栈清晰。
2. 显示：移动端竖屏、深色模式、大号字体和长题干没有溢出，操作按钮不被系统手势条遮挡。
3. 格式：可读 CSV/TSV/JSON/TXT；XLSX 等不应在原型中宣称已解析。
4. 字段映射：修改映射后，候选内容应按照新映射重新生成（对于原型可读取类型）。
5. 错题导入：将 `A,Z` 修正为 `A,C` 后，错误计数从 1 变 0。
6. 重复题：选择跳过、替换和保留双版本，应反映在导入结果中。
7. 跨库审查：相同题干不同答案显示冲突；“已核对”不能直接删除学习记录。
8. 答题：单选仅一项、多选可多项；提交后显示解析；跳题后能查看作答状态。
9. JSON 导出：生成包含题目及元数据的文件，成功导出不应修改题库。
10. 原生落地：实际 Excel 必须配套真实文件回归测试、解析性能数据和事务测试。
